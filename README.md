# Keneth Njoroge - Personal Portfolio

A modern, responsive, and eye-catching personal portfolio website built with **Flask**, **Bootstrap 5**, **HTML5**, **CSS3**, and **JavaScript**.

Designed to showcase my skills as a **Software Engineer** with a strong focus on **AI**, **Machine Learning**, and **Full-Stack Development**.

![Portfolio Preview](https://keneth-portfolio-grandistechconsultancy.vercel.app)

## ✨ Features

- **Fully Responsive** design (mobile-first)
- **Modern Dark Theme** with smooth animations
- **Four Pages**: Home, About, Projects, Contact
- **Flask Backend** with clean routing
- **Interactive UI** with hover effects and scroll animations
- **Ready for Vercel Deployment**
- **Creative Commons Licensed**

## 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Styling**: Custom CSS with smooth transitions
- **Deployment**: Vercel
- **License**: Creative Commons Attribution 4.0 (CC BY 4.0)
